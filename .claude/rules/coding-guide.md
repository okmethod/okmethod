# コーディング規約

言語非依存の実装の指針を示す。言語固有の書き方は `typescript-guide.md` / `svelte-guide.md` / `python-guide.md` を参照。

> このファイルは全PJ共通の核。各PJでは必要に応じて globs のみ上書きする。

## 開発規約

- **命名**: 目的と中身がわかる名前を付ける。曖昧語・安易な略語を避ける
- **関数**: 単一責務・適切な粒度（1 関数 1 目的）
- **明確さ優先**: 簡潔さより明確さ。複雑な式は一時変数に分解して意図を示す
- **コメント**: **日本語文**を基本とする。「何を（What）」よりも「なぜ（Why）」を書く
- **ログ・エラーメッセージ**: **英文**を基本とする
- **YAGNI**: 今不要な汎用化をしない。抽象化は同じパターンが 3 回現れてから。まず動くシンプルな実装、必要になったらリファクタリング
- **負債の明示**: 未実装・負債はコメントで明示する（`TODO:` / `FIXME:`。行コメント記号は言語に従う）
