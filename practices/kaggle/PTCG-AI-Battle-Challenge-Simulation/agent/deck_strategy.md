# デッキ戦略

参考: [A Sample Rule-Based Agent Mega Lucario ex Deck](https://www.kaggle.com/code/kiyotah/a-sample-rule-based-agent-mega-lucario-ex-deck/notebook#Rule-Based-Agent-for-Mega-Lucario-ex)

## 1. デッキの基本コンセプト

メガルカリオexをメインアタッカーとしつつ、ハリテヤマ・ソルロックを状況に応じて使い分ける柔軟なデッキ。

- **メガルカリオex**: 高火力アタッカー。エネルギー2枚で270ダメージの「メガブレイブ」が主力
- **ハリテヤマ**: エネルギー3枚で210ダメージ。メガルカリオexが使えない場面のサブアタッカー
- **ソルロック**: ルナトーンが場にいる場合、エネルギー1枚で70ダメージ。つなぎアタッカー

## 2. 序盤の場作り(初手〜数ターン)

- **先攻の場合**: リオルをバトル場に出す（進化してメガルカリオexに育てるため）
- **後攻の場合**: ソルロックをバトル場に出す（1エネで即攻撃できるため）
- ルナトーンのアビリティでドローを加速しながら手札を整える
- ゼイユ・リーリエの決心でさらに手札を補充

## 3. 進化の優先順位

1. リオル → メガルカリオex（メインアタッカー確保）
2. マクノシタ → ハリテヤマ（相手がバトル場から逃げられない状況で進化しサブアタッカーへ）
   - ただし相手のバトルポケモンを倒せるターンはあえて進化を待つ

## 4. エネルギー管理

- エネルギーはメガルカリオex・ハリテヤマへ優先的に付ける
- ソルロックへのエネ付けは1枚まで（2枚以上は無駄）
- ルナトーンにはエネルギーを付けない
- 「メガブレイブ（270）」発動条件はエネルギー2枚。足りなければその場でハンドから付けて攻撃

## 5. 撤退・入れ替えの方針

- 攻撃計画（`AttackPlan`）でベンチのアタッカーが攻撃できると判断した場合のみ入れ替える
- ポケモンいれかえはベンチアタッカーへのスイッチに使い、無駄打ちしない

## 6. 勝ち筋の考え方

- 基本は**メガルカリオexでサイドを2枚取り続けるワンパン戦略**
- 相手のサイドが残り1枚以下になる攻撃があればスコア50000で最優先実行
- ボスの指令でベンチの高価値ポケモン（サイド2枚取れる相手）を呼び出して倒す
- 弱点（闘タイプ弱点）の相手にはダメージが2倍になるため積極的に攻める
- メガルカリオexのサイドが2〜3枚のタイミング（相手が詰め段階）では逆にメガブレイブ（270）を控え、ファーストアタック（130）で立ち回る

## 7. 実装上のスコアリング方針(要約)

各行動に数値スコアを割り当て、降順で選択する単純なヒューリスティック。

| スコア帯 | 行動の優先度                             |
| -------- | ---------------------------------------- |
| 50000    | 勝利確定の攻撃                           |
| 30000    | アビリティ使用（ルミオスシティを除く）   |
| 20000    | ポケモンをベンチに出す                   |
| 10000    | トレーナーズを使う（基準値）             |
| 9000     | 進化                                     |
| 8000     | エネルギー付け                           |
| 6000     | ポケモンいれかえ                         |
| 1000     | 攻撃                                     |
| 0        | ターン終了（END）など                    |
| -1       | 使いたくない行動（条件を満たさない場合） |
