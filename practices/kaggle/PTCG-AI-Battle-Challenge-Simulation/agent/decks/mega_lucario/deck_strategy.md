# デッキ戦略:メガルカリオex

参考: [A Sample Rule-Based Agent Mega Lucario ex Deck](https://www.kaggle.com/code/kiyotah/a-sample-rule-based-agent-mega-lucario-ex-deck/notebook#Rule-Based-Agent-for-Mega-Lucario-ex)

## 1. デッキの基本コンセプト

メガルカリオexをメインアタッカーとしつつ、ハリテヤマ・ソルロックを状況に応じて使い分ける柔軟なデッキ。

- **メガルカリオex**: 高火力アタッカー。エネルギー2枚で270ダメージの「メガブレイブ」が主力
- **ハリテヤマ**: エネルギー3枚で210ダメージ。メガルカリオexが使えない場面のサブアタッカー
- **ソルロック**: ルナトーンが場にいる場合、エネルギー1枚で70ダメージ。つなぎアタッカー

## 2. 序盤の場作り(初手〜数ターン)

- **先攻の場合**: リオルをバトル場に出す（進化してメガルカリオexに育てるため）
- **後攻の場合**: ソルロックをバトル場に出す（1エネで即攻撃できるため）
- ルナトーンのアビリティでドローを加速しながら手札を整える
- ゼイユ・リーリエの決心でさらに手札を補充

## 3. 進化の優先順位

1. リオル → メガルカリオex（メインアタッカー確保）
2. マクノシタ → ハリテヤマ（相手がバトル場から逃げられない状況で進化しサブアタッカーへ）
   - ただし相手のバトルポケモンを倒せるターンはあえて進化を待つ

## 4. エネルギー管理

- エネルギーはメガルカリオex・ハリテヤマへ優先的に付ける
- ソルロックへのエネ付けは1枚まで（2枚以上は無駄）
- ルナトーンにはエネルギーを付けない
- 「メガブレイブ（270）」発動条件はエネルギー2枚。足りなければその場でハンドから付けて攻撃
- マクノシタもハリテヤマと同等の3エネ210ダメージで攻撃可能（ただし進化できる場面では進化優先）

## 5. 撤退・入れ替えの方針

- 攻撃計画（`AttackPlan`）でベンチのアタッカーが攻撃できると判断した場合のみ入れ替える
- ポケモンいれかえはベンチアタッカーへのスイッチに使い、無駄打ちしない

## 6. 勝ち筋の考え方

- 基本は**メガルカリオexでサイドを2枚取り続けるワンパン戦略**
- 相手のサイドが残り1枚以下になる攻撃があればスコア50000で最優先実行
- ボスの指令でベンチの高価値ポケモン（サイド2枚取れる相手）を呼び出して倒す
- 弱点（闘タイプ弱点）の相手にはダメージが2倍になるため積極的に攻める
- メガルカリオexのサイドが2〜3枚のタイミング（相手が詰め段階）では逆にメガブレイブ（270）を控え、はどうづき（130）で立ち回る

### 攻撃対象の優先度スコア補正

基準スコア = サイド枚数×1000 + エネ数×150 + ツール数×100 + 進化段階ボーナス（stage2: +250、stage1: +130）+ HP値

| カード                                          | 補正 | 理由                         |
| ----------------------------------------------- | ---- | ---------------------------- |
| ヨルノズク / スピンロトム / ブリジュラスex / ニャースex | −200 | 撃破優先度低（脅威が小さい） |
| マシマシラ（エネ1枚以上）                               | +300 | エネ保有時に特に危険         |

## 7. 実装上のスコアリング方針（詳細）

各行動に数値スコアを割り当て、降順で選択する単純なヒューリスティック。

| スコア帯 | 行動                         | 条件                                                                |
| -------- | ---------------------------- | ------------------------------------------------------------------- |
| 50000    | 勝利確定の攻撃               | 残りサイドが取れる枚数以下になる攻撃                                |
| 30000    | アビリティ使用               | ミアレシティ以外                                                    |
| 20000    | ポケモンをベンチに出す       | 重複上限（ルナ/ソル: 1、リオル+メガルカ: 計2）未満                  |
| 10000    | トレーナーズを使う（基準値） | スタジアムは未設置時のみ                                            |
| 9000+    | 進化                         | 基準 9000 + アタッカーのエネ数。マクノシタはバトル場攻撃計画中に −1 |
| 8000+    | エネルギー手張り             | ポケモン種別・準備状況で ±補正。計画中アタッカーへ +200             |
| 7000+    | ヒーローマント装着           | メガルカリオex: +200、リオル: +100                                  |
| 6000     | ポケモンいれかえ使用         | ベンチに攻撃計画ポケモンがいる場合のみ                              |
| 2000     | 撤退                         | ベンチに攻撃可能なポケモンがいる場合のみ                            |
| 1000+    | 攻撃                         | 攻撃計画のワザと一致で +100                                         |
| 1        | ミアレシティ特性             | 通常特性（30000）の代替手段として低優先                             |
| 0        | ターン終了（END）など        | デフォルト                                                          |
| -1       | 使いたくない行動             | 条件を満たさない場合に明示的に返す                                  |

### カード選択時の優先度（サーチ・ドロー効果）

トレーナー効果でカードを手札に加える際に動作する優先度。
場・手札の枚数を見て過剰なカードを低優先にし、戦略上必要なカードを優先的に拾う。

| カード                  | 優先ロジック                                       |
| ----------------------- | -------------------------------------------------- |
| マクノシタ              | 場に未展開なら +10、展開済みなら −10               |
| ハリテヤマ              | 場にマクノシタがいれば +20、いなければ −20         |
| ルナトーン / ソルロック | 場に未展開なら大幅加点、展開済みなら −250          |
| リオル                  | 場のリオル+メガルカリオex 合計で優先度調整         |
| 格闘エネルギー          | ルナトーンアビリティ未使用 or 手張り未実施なら +30 |
