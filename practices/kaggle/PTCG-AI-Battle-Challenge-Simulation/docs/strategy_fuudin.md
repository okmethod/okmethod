# デッキ戦略:フーディンデッキ

参考: note記事 [フーディンデッキの考え方](https://note.com/smasakichi/n/nd5426f7cf1dc)

---

## 1. デッキの基本コンセプト

フーディンは「ハンドパワー」(手札枚数×20ダメージ、コスト超エネルギー1枚)で攻撃する、このデッキで唯一攻撃するポケモンです。ケーシィ→ユンゲラー→フーディンという進化ラインを育てながら、手札をできるだけ大きく保つことがすべての土台になります。

- ケーシィ→ユンゲラーは「テレポートアタック」持ち(HP40超)の型を優先。
- ユンゲラーは進化時に「サイコドロー」(2枚ドロー)を持つため、ふしぎなアメでケーシィから直接フーディンへ進化してこのトリガーを飛ばすことは基本的に避ける(ワンチャンス的にどうしても他に良い選択肢がない場合を除き優先度を下げる)。
- ノコッチ/ノココッチはバトル場の壁として序盤〜中盤を支え、ノココッチの特性「にげあしドロー」(3枚ドロー後、自身と付いているカードをデッキに戻す)で盤面をリソースに変換する。
- リッチエネルギーはノコッチ/ノココッチにのみ付け、にげあしドローで手札に戻すことで「エネルギーをつけた瞬間に4枚ドロー」の効果を何度も再利用する。フーディンに付けてしまうとこのループが壊れるため、基本的に付けない。ただし、終盤にサイドを取りきる見込みがあるときはフーディンにつけてもよい。
- キチキギスexは「自分のポケモンが相手ターン中にきぜつした時に手札を多く引く」特性を持つが、自分から進んでバトル場に出す価値はない。攻撃技も使わない。

## 2. 序盤の場作り(初手〜数ターン)

理想的な展開順序は、ケーシィ(1)→ケーシィ(2)→ノコッチ(1)→ノコッチ(2)→ケーシィ(3)→ノコッチ(3) の順で、最終的にケーシィ3枚・ノコッチ2〜3枚を場に揃えることを目標とします。

- ケーシィは3枚を目標とし、既に3枚場に出ている状態で4枚目を出すよりはノコッチを優先して展開する(ケーシィのスコアを4枚目以降は下げ、ノコッチが選ばれやすくする)。
- バトル場は退場コスト0のノコッチに任せ、序盤の被ダメージを受け止める壁として運用する。
- 目標とする戦闘フェーズの盤面: フーディン(バトル場)、ユンゲラー、ケーシィ、ノコッチ、ノコッチ(ベンチ)。

## 3. 進化の優先順位

- ケーシィ→ユンゲラー→フーディンの正規ルートを優先し、フーディンへの進化時にはできるだけ多くエネルギーの付いた個体を選ぶ。具体的には、「エネルギーが付いているユンゲラーを進化させればそのターンに攻撃できる」状況で、エネルギーの付いていない(進化させても攻撃できない)ユンゲラーを誤って進化させることがないよう、進化先候補のスコアはエネルギー数を強く重み付けして評価する。
- バトル場のノコッチをノココッチへ進化させる判断は、そのターンにフーディンで攻撃できるプラン(ベンチのフーディンを出して攻撃する等)が既にある場合は優先度を大きく下げる。「進化はできるが攻撃機会を逃す」ことがないよう、攻撃(または攻撃のための入れ替え)を進化より優先する。逆に今ターン攻撃の見込みがなければ、通常通りベンチのノコッチと同様にノココッチへ進化させ、にげあしドローの準備を進めてよい。

## 4. エネルギー管理

- フーディン・ユンゲラー・ケーシィそれぞれについて、攻撃に必要な最低限(1枚)のエネルギーが既に付いていれば、それ以上そのラインに通常エネルギーを追加したり、ワンダーパッチを使ったりしない。場に出ている対象ポケモン全て(フーディン・ユンゲラー・ケーシィ)が1枚以上のエネルギーを持っている状態になったら、エネルギーとワンダーパッチは温存し、無駄な先打ちを避ける。
- リッチエネルギーは上記の温存ルールの対象外とし、ノコッチ/ノココッチへの供給は通常通り継続する(リッチエネルギーループを止めないため)。
- ワンダーパッチの想定使用手順:
  1. ノココッチをバトル場に出す
  2. ワンダーパッチで、基本エネルギー(テレパスエネルギーは対象外)を
     手札から捨て札を経由してベンチの超タイプポケモンへ付ける
  3. バトル場のノココッチで「にげあしドロー」を使用し、バトル場を空ける
  4. ベンチのフーディンをバトル場に出す
- ノココッチの「にげあしドロー」は、そのターンに攻撃もできる状況でも**攻撃より先に使う**。特性を使わずにポケモンがきぜつすると手札とリッチエネルギーをまとめて失うため、特性→攻撃の順を徹底する。

## 5. 撤退・入れ替えの方針

- バトル場のノコッチは、フーディンに攻撃の目処が立ち次第、積極的にフーディンと入れ替える。
- キチキギスexは、自分の意思でバトル場に出すことは基本的に行わない(他に選べる選択肢がない場合を除く)。フーディンが倒された直後にキチキギスexへ交代してしまう挙動は不具合として修正済み。
- 対戦相手がメガルカリオ系のデッキ(メガルカリオex、ルカリオの元となるリオル等を確認)の場合、低HP・退場コスト0のノコッチをバトル場に出したままターンを終えることは、可能な限り避ける。これは相手のソルロックにノコッチが簡単に倒されるため。フーディンの攻撃準備が整っていなくても、他に出せるポケモンがあれば入れ替えを優先する。

## 6. 勝ち筋の考え方

このデッキは6枚のサイドを愚直に殴り合いだけで取り切る必要はありません。
フーディンによる2〜4回程度の「理想的な一撃」と、ボスの指令によるベンチ狙撃を組み合わせ、効率よくサイドを取ることを目指します。非ルール(exでない)ポケモンが中心のため、1回のきぜつで渡すサイドが1枚で済む点も、ex中心の相手デッキに対するアドバンテージです。

「相手を一撃で倒せない」状態での攻撃は基本的に非推奨。半端なダメージを与えても手札消費の無駄になり、1ターン待って手札を蓄積してから一撃を狙う方が勝率は高い。手札が少ない状態でも他にとれる行動(特性・進化・エネルギー付与等)があればそちらを優先し、打つべき一撃の準備を整えてから攻撃に移る。

一方でこのデッキの弱点は低耐久(最大HPも140程度)であるため、速攻や妨害に弱い面があります。ノコッチ/ノココッチを壁として使い切り、リッチエネルギーを保持したノココッチをきぜつさせない(きぜつするとリッチエネルギーループを完全に失う)ことが、長期的な安定運用の鍵です。

### 攻撃対象の優先度スコア

基準スコア = サイド枚数×1000 + エネ数×150 + ツール数×100 + 進化段階ボーナス（stage2: +250、stage1: +130）+ HP値

フーディン特有の相手カード固有補正はなし（ハンドパワーのダメージ計算で「一撃で倒せる相手」が自然に高スコアになる設計のため）。

### カード選択時の優先度（サーチ・ドロー効果）

トレーナー効果でカードを手札に加える際（TO_HAND コンテキスト）の優先度。
基準スコア = 200 − 手札内重複枚数×100

| カード              | 優先ロジック                                    |
| ------------------- | ----------------------------------------------- |
| ケーシィ            | 場のフーディンライン合計 < 3枚: +30、≥ 3枚: −50 |
| ユンゲラー          | 場にケーシィがいれば: +20、いなければ: −10      |
| フーディン          | 場にユンゲラーがいれば: +30、いなければ: +10    |
| ノコッチ            | 場のノコッチライン合計 < 2体: +20、≥ 2体: −50   |
| ノココッチ          | 場にノコッチがいれば: +15、いなければ: −20      |
| リッチエネルギー    | +50（最優先で回収）                             |
| 基本/テレパス超エネ | +10                                             |
